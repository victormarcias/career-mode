# Outreach messages — Lucía Marín

The demo's messages: invented, with an invented person. Each template is a heading, one subheading per language, and the text in a code block so its line breaks stay exactly as written. Placeholders: `_nombre_` / `_name_`, `_puesto_` / `_position_`, `platform_recruiter`, `platform_post_id`.

## 📝 Platform Reachout Message

