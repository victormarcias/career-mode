# submit-profile

The user's profile as a quick reference for filling candidate-portal wizards and
any form that asks for roles, stack, compensation, English level, experience or
a bio. The data lives in `profile/profile.md` (gitignored; `profile/README.md`
explains how to fill it from a CV), and the skill says how to use it: the
priority order, what is never added, how to fill a profile builder and which
portals already have a full profile.

The CV is the file of the `CV_PDF_PATH` setting and the photo is
`profile/photo.*`. A field that says `(not set)` is asked of the user, never
guessed; open questions are written from the profile's "How I work" section and
the CV, and only a hard fact the profile lacks is asked. Use it whenever such a
form comes up or a portal's profile is updated. Instructions:
[SKILL.md](SKILL.md).
