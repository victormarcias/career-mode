# submit-profile

The user's profile as a quick reference for filling candidate-portal wizards ("LinkedIn clones") and any form that asks for roles, stack, compensation, English level, experience or a bio.

- **The data** is in `profile/profile.md` (gitignored, so it stays on this computer; the template is `profile/profile.example.md`, and `profile/README.md` says how to fill it from a CV), not in this skill. The skill says how to use it: priority order, what never to add, how to fill a profile builder, and the list of portals already built out.
- **Use it when:** a form asks for roles, stack, compensation, English level, experience or a bio, or when updating a portal's profile.
- **CV and photo:** the CV is the file of the `CV_PDF_PATH` setting; the photo is `profile/photo.*`, the picture uploaded in Settings.
- **A field that says `(not set)`** is asked of the user when a form needs it, never guessed.
- **Source of truth:** the user's CV. Tech per role comes from each role's own "Tech:" line, never padded from the wishlist.

Instructions: [SKILL.md](SKILL.md).
