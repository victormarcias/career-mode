# wake-up

The morning routine in one command: it runs `/links-inbox` to queue the new
links of a chat group, `/apply-pending` to
apply to everything in the queue and `/digest-email` for the mailbox, and ends
with their tables, painted by what you have to do: red when you must act,
green when it is done.

It touches only what those skills touch. Instructions: [SKILL.md](SKILL.md).
