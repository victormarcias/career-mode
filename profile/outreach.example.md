# Outreach messages — Your Name

The message templates the Outreach tab shows. Each template is a heading, one subheading per language, and the text in a code block so its line breaks stay exactly as written. A platform is wherever you apply or talk to recruiters. Placeholders: `_nombre_` / `_name_`, `_puesto_` / `_position_`, `platform_recruiter`, `platform_post_id`.

## 📝 Platform Reachout Message

### 🇪🇸 Spanish

```
Tu mensaje para contactar primero. Saludá con _nombre_.
```

### 🇬🇧 English

```
Your message to reach out first. Greet them with _name_.
```
